# 專案 Roadmap

## 第一階段：建立專案與版本控制

- 建立單一 Git 專案，包含 Expo App 與公開介紹網站。
- 設定 `main` 作為穩定版本分支。
- 將 GitHub 遠端指向 `AngleZero-collab/ai-walk-buddy`。

## 第二階段：公開介紹網站

- 說明高齡行人過馬路痛點。
- 呈現 App 的綠色通過與紅色退回提示示意。
- 說明 Edge AI 本機處理與隱私優先架構。

## 第三階段：完善 App

- 強化相機、定位與感測器權限狀態處理。
- 將 Demo 的隨機秒數模擬封裝成可替換的本機辨識介面。
- 補上更完整的無障礙提示與動態字級支援。
- 為核心決策公式與狀態切換建立測試。

## 第四階段：模型整合預留

- 保留 JSI / Native Modules 介面，後續串接 C/C++ 輕量化視覺辨識模型。
- 確保影格處理完成後立即釋放，不保存或上傳隱私資料。
